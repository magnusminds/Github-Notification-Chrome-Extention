Configure your notification preferences

Authentication

A Personal Access Token is optional. Leave it blank to use session mode — the extension reads your notifications straight from github.com/notifications using your existing logged-in session, no token needed. Add a token only if you want the faster, structured GitHub API (and the participating filter). The token is stored locally in your browser and never shared.

Optional — for API mode, create a token at github.com/settings/tokens with the notifications scope. Leave blank to use session mode.
